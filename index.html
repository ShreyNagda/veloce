Configure your Next.js project and generate the command to get started instantly.

📚 How to Use This Tool

Configure your Next.js project options below. The generated command will appear at the bottom. Copy and run it in your terminal to create your project.

Always review commands before running them. Refer to the official Next.js documentation for more details.
